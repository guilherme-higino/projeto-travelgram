# 📄 Projeto - TravelGram ✈️

Landing page desenvolvida com HTML5 e CSS3 como parte do curso de formação Full-Stack da Rocketseat.

O projeto simula o layout de uma rede social de viagens chamada Travelgram, apresentando o perfil de uma viajante e uma galeria de fotos dos destinos visitados.

---

## 🚀 Tecnologias Utilizadas

- HTML5: Estruturação semântica da página.

- CSS3: Estilização completa, incluindo:

  Uso de Flexbox para composição de layout e alinhamento responsivo.

  Tipografia personalizada (fontes do Google Fonts).

  Esquema de cores e espaçamentos harmoniosos.

---

## 🎯 Objetivos do Projeto

- Este projeto foi desenvolvido com o objetivo de:

  Praticar estruturação de páginas com HTML5

  Aplicar estilização moderna com CSS3

  Trabalhar com layouts utilizando Flexbox

  Reproduzir um layout fiel a um protótipo (desafio prático)

  Desenvolver atenção a detalhes visuais

---

## 🖥️ Layout da Aplicação

-A landing page contém:

    🔎 Header com navegação

    👩‍💻 Seção de perfil do usuário

    📍 Informações de localização e estatísticas

    🖼️ Galeria de imagens organizada em grid

    🎨 Design moderno e limpo

## ▶️ Como visualizar o projeto

- Clone o repositório:


